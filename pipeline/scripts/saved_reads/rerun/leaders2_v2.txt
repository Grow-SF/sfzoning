This is a crop of a scanned 2000 San Francisco zoning map, {w} x {h} pixels (origin top-left).
A district code (read as "{code}") is printed at the centre, circled in red.

Step 1. Read the circled code exactly as printed (for example RH-1, RM-2, NC-3, P) into code_read.

Step 2. Find the area the code names. Areas are bounded by heavy, thick lines (district boundaries).
Usually the code is printed inside its own area, with no leader.

But a small or narrow area cannot hold its code, so the code is printed just outside it and tied to
it by a leader. On these maps leaders look like:
- a short thin line or curve from the letters into a small area outlined by heavy lines nearby
  (a single lot or a small box), often ending in a small arrowhead;
- a bracket "{", "(" or ")" beside the letters, facing a narrow strip;
- an arrow from the letters to a spot across a street.
Not leaders: the hyphen inside the code (RH-1), a heavy boundary line (never follow one), or letters
that simply overlap a line.

Look closely at the thin strokes touching or right next to the letters before deciding.

If there is a leader, give the pixel where it ends, inside the area it names (at the arrowhead, just
past the end of the line, or inside the strip or box the bracket faces). Otherwise answer has_leader
false and give the code's own centre.
