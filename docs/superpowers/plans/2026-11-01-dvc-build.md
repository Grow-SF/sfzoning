# Tracked, parallel pipeline builds (DVC) — implementation plan

**Goal:** Hand-made inputs in git; DVC records every build step's inputs and outputs;
`sfzmaps build -j 8` rebuilds what is stale in parallel without spending money.

**Spec:** `docs/superpowers/specs/2026-11-01-dvc-build-design.md`

**Execution:** native (implemented in-session), one fresh whole-branch review at the end. *(my
call: the tasks share interfaces tightly and the owner is asleep; one reviewer on the whole
branch catches more than per-task reviews of small diffs.)*

## Global constraints

- Never commit `pipeline/data/`. Never print or commit secrets (`pipeline/.env`, `site/.env.local`).
- No live OpenAI calls anywhere in this work (spend $0).
- Don't change placements, district reads or published data. The migration moves files; it must
  not change any build output (checked by `dvc status` after adoption and a no-op build).
- Tests: `cd pipeline && uv run pytest` green.
- DVC cache type `reflink,copy` only.

## Review focus

1. A `review.json` saved by the editor after migration must land in `inputs/reviews/` and be
   what the runner reads next (test through the editor's save path).
2. Old bundles that still contain `work/*/*/review.json`: `pull` must not resurrect them into
   `data/work/` (test).
3. A stage failure must not commit, and its downstream stages must be skipped (test).
4. A live call inside `sfzmaps stage` must fail the stage, not degrade output (test).
5. Committed `dvc.yaml` drifting from the generator (test).

  `path.parent.name` when it exists (top-level keys replace).

### Task 3: `sfzmaps stage <name>`

**Interfaces:** `build.STAGES: dict[str, Stage]` where `Stage(name, series: list[str],
districts: list[str], deps: list[str], outs: list[str], upstream: list[str])`;
`sfzmaps stage NAME` runs, for `edition@E`/`period@P`: `run --year S` for each series, `paper
--year S` for each, then `districts --series S` for each in `districts` order; `today`:
districts today; `shared`: districts --shared. Sets `SFZMAPS_MAX_USD=0` in its environment.
Calls the existing CLI functions in-process via subprocess of `sfzmaps` (one process per
command, so the CLI's own exit handling and logging stay as they are). *(my call)*

- [ ] Tests: STAGES covers every SERIES entry exactly once (non-skip and skip), periods put
  height districts before zoning; `stage` builds the right command list (dry list function
  `stage_commands(name) -> list[list[str]]`), each with `SFZMAPS_MAX_USD=0`; first failing command
  stops the stage with its exit code; `ask_json` with `SFZMAPS_MAX_USD=0` and no cache raises
  `LLMQuotaError` without calling the client.
- [ ] Implement in `src/sfzmaps/build.py` + cli command. Commit.

commit=...)` with injectable callables for tests.

- [ ] Tests: committed `pipeline/dvc.yaml == build.dvc_yaml()`; `plan_run` adds downstream
